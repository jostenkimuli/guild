Styling & theming

  • Tailwind v4 CSS-first config: globals.css imports tailwindcss, tw-animate-css, shadcn/tailwind.css.
  • Full oklch color system with light/dark themes via .dark class and @theme inline mapping CSS variables to Tailwind tokens.
  • Base radius 0.625rem; dedicated sidebar color tokens.
  • cn() from lib/utils.ts (clsx + tailwind-merge) is the single class-merge helper.
  • Icons: lucide-react.
