What is TheGuild?

TheGuild is an educational ecosystem platform: super admins onboard program admins, who onboard ecosystem admins, who create and run ecosystems (schools, universities, companies). Inside an ecosystem live spaces (departments, innovation hubs, project groups). Spaces ship a full curriculum — grades → terms → units → topics → lessons — with syllabi, learning objectives, activities, assessments and shared resources. Learners join spaces via invitation codes and follow published lessons; teachers plan, publish and deliver them.

The roadmap adds mentors (Sprint 3), teams (Sprint 4), challenges (Sprint 5), projects (Sprint 6) and cross-ecosystem alliances (Sprints 7–8). The platform compiles to a production build today and is developed against a local Supabase stack with disciplined migrations, row-level security and typed clients.

Domain at a glance

The product is modeled as Ecosystem → Space → (Content / Challenge → Team → Project), with users holding per-space roles (Teacher / Learner / Mentor / Industry Partner).

Entities
Ecosystems, Spaces, curricula, lessons, syllabi — and the roadmap entities: teams, challenges, projects.
Roles & approvals
super_admin → program_admin → ecosystem_admin → space_admin, with delegation and invitation codes.
Schema
29+ tables across migrations, all with RLS and explicit grants, regenerated TS types.
Routes
Landing, login, dashboards by role, ecosystem → space pages, lesson views and publishing.
Server actions
Onboarding, approvals, ecosystems, spaces, invitations, curricula, syllabi and lesson delivery.
Architecture
Server-first rendering, session-refresh proxy, subdomain rewriting, typed Supabase clients.

Quick start

Bootstrap the full local environment
npm install                 # install dependencies
npm run db:start            # start local Supabase (Docker)
copy .env.example .env.local # then fill in the keys from `supabase status`
npm run db:reset            # apply migrations + seed
npm run dev                 # dev server on http://localhost:3000
Windows note
Use npm.cmd and supabase.cmd instead of the bare commands — this host blocks the *.ps1 shims. Local Supabase ports are remapped (API 55421, DB 55422, Studio 55423); see Setup & Prerequisites.
