Subdomain mirror
The proxy rewrites ecosystem subdomains to these routes — e.g. a-sample-school.localhost:3000 → /ecosystem/a-sample-school. See Architecture → Subdomains.

Route restructure notes

docs/ROUTE_RESTRUCTURE.md records the move away from the old /console/ routing. Decisions that still guide the app:

  • Spaces keep bookmarkable URLs at /spaces/[slug].
  • Ecosystem routes use [slug], not [id], for readable, stable URLs.
  • Cross-cutting admin lives at /admin, separate from ecosystem-bound areas.
